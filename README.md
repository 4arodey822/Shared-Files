Описание: \
Программа решает систему линейных уравнений методом Жордана с выбором главного элемента по всей матрице. Вычисления проводятся с типом данных double без дополнительных алгоритмов уменьшения погрешности, при сборке компилируется с ключом оптимизации -O3 \
 \
Сборка: \
Все файлы поместить в одну папку. Открыть консоль в папке (с помощью контекстного меню). Ввести (после // комментарии): \
mkdir build // создаёт папку build \
cd build // переход консоли в папку build \
cmake .. // запуск cmake с указанием того, что файл CMakeLists.txt лежит на папку выше \
make // сама компиляция \
 \
Запуск программы: \
Ввести в консоль: \
./solution n m k file \
где вместо n, m, k, file стоят конкретные значения аргументов \
Примеры: \
./solution 2000 6 4 \
./solution 50 4 0 Matrix.txt \
Если используется файл, из которого считывается матрица, то его нужно поместить в папку build
